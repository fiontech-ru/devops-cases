# TICKET: 502 после пересборки образа (FPM IPv6-only)

**Приоритет:** High (блокирует работу)  
**Автор:** DevOps (обнаружено при деплое)  
**Статус:** Resolved  

## Описание

После перехода на `php:8.2.35-fpm` Nginx получает 502, в логах `connect() failed (111: Connection refused)`. FPM слушает только IPv6 (`[::]:9000`), IPv4-сокета нет.

## Решение

`sed` по `docker.conf`: `listen = 0.0.0.0:9000`.

## Результат

Nginx подключается по IPv4, 502 исчез.
