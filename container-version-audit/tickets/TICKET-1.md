# TICKET: аудит и обновление версий PHP/Nginx в контейнерах

**Приоритет:** High (критические CVE)
**Автор:** DevOps
**Статус:** Resolved

## Описание
После выхода CVE-2026-109618/109619 (PHP RCE, CVSS 9.2)
и уязвимостей Nginx нужно проверить все контейнеры на уязвимые
версии.

## Диагностика
Написан скрипт `check-php-nginx-versions.py` (перебирает
запущенные контейнеры, проверяет `php -v` и `nginx -v`).
Найдено: PHP 8.3.30, 8.4.18/23; Nginx 1.25.2, 1.29.4.

## Решение
PHP пересобран на `php:8.3.36-fpm` / `php:8.4.27-fpm`;
Nginx заменён на `nginx:1.31.8-alpine`.

## Результат
Повторный аудит: все контейнеры на безопасных версиях
(PHP 8.2.35/8.3.36/8.4.27, Nginx 1.31.8). CVE закрыты.
