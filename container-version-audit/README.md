# Кейс: аудит версий PHP и Nginx в контейнерах

После выхода критических CVE в PHP (CVE-2026-109618/109619, RCE,
CVSS 9.2) и серии уязвимостей в Nginx нужно было проверить все
запущенные контейнеры на уязвимые версии и обновить их.

## Проблема

На одном VDS работает множество контейнеров (10+ проектов):
Laravel-приложения, Nginx, Redis, MySQL. Версии PHP и Nginx
в них не проверялись централизованно. После выхода критических
CVE стало понятно, что часть контейнеров использует уязвимые
версии.

## Что сделано

### 1. Скрипт аудита `check-php-nginx-versions.py`

Написан bash-скрипт, который:
- перебирает все запущенные контейнеры (`docker ps`);
- проверяет наличие и версию PHP (`php -v`) и Nginx (`nginx -v`);
- выводит три списка для каждого бинарника: **найден** (с версией),
  **не найден**, **ошибка проверки** (например, контейнер в
  `Restarting` или нет `sh`).

Скрипт не зависит от `bash` внутри контейнера (использует `sh -c`),
работает и в Alpine, и в Debian.

### 2. Результат аудита (исходное состояние)

**PHP — уязвимые версии:**
- `app-rustblog` — 8.4.23 (нужно ≥ 8.4.27)
- `hexlet-phpunit-app`, `brain-games-app` — 8.4.18 (нужно ≥ 8.4.27)
- `gogpt-*`, `ms-el2-*`, `testprj-app` — 8.3.30 (нужно ≥ 8.3.36)

**Nginx — уязвимые версии:**
- `blog-*`, `h500`, `cars`, `anime`, `fullstack-landing`,
  `gogpt-webserver`, `webserver-ms-el2` — **1.25.2** (нужно ≥ 1.30.6)
- `brain-games-nginx` — 1.29.4 (нужно ≥ 1.31.7)

### 3. Обновление

- **PHP:** пересобраны образы с безопасными базовыми:
  `php:8.3.36-fpm` (gogpt, ms-el2, testprj),
  `php:8.4.27-fpm` (rustblog, hexlet-phpunit, brain-games).
- **Nginx:** заменён плавающий тег `nginx:alpine` на фиксированный
  `nginx:1.31.8-alpine`. Пересозданы контейнеры.

### 4. Повторный аудит

После обновления скрипт запущен снова. Все контейнеры используют
безопасные версии:
- PHP: 8.2.35, 8.3.36, 8.4.27.
- Nginx: 1.31.8.

`nginxproxymanager` (openresty/1.27.1.2) — отдельная ветка,
проверяется по своим security-адвизори, не входит в этот аудит.

|---|---|---|---|---|
| `blog-*` | 8.2.35 | 8.2.35 | 1.25.2 | **1.31.8** |
| `gogpt-*` | 8.3.30 | **8.3.36** | 1.25.2 | **1.31.8** |
| `testprj-*` | 8.3.30 | **8.3.36** | 1.25.2 | **1.31.8** |
| `brain-games` | 8.4.18 | **8.4.27** | 1.29.4 | **1.31.8** |
| `hexlet-phpunit` | 8.4.18 | **8.4.27** | 1.29.4 | **1.31.8** |

**Закрыто:**
- CVE-2026-109618/109619 (PHP RCE, CVSS 9.2) — во всех
  обновлённых контейнерах.
- Уязвимости Nginx 1.25.2 / 1.29.4 — заменены на 1.31.8.

## Что бы я сделал иначе

- **Зафиксировать теги образов** (`nginx:1.31.8-alpine` вместо
  `nginx:alpine`, `php:8.3.36-fpm` вместо `php:8.3-fpm`), чтобы
  не зависеть от плавающих тегов.
- **Добавить `check-php-nginx-versions.sh` в CI** — регулярный
  аудит при каждом деплое, а не разовая проверка.
